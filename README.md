#  AI Resume Analyzer

An AI-powered tool that instantly analyzes your CV and gives you a score out of 100 with detailed feedback.

## 🚀 Live Demo
👉 [Try it here](https://cv-analyzer-h2pa.onrender.com)

## ✨ Features
- 📄 Upload your CV in PDF format
- 🤖 AI analyzes it instantly
- 📊 Get a score out of 100
- ✅ Detailed feedback on weak sections
- 💡 Suggestions to improve your CV

## 🛠️ Built With
- Python
- Flask
- PyMuPDF
- HTML/CSS

## 📦 How to Run Locally
```bash
git clone https://github.com/Jalalab/cv-analyzer
cd cv-analyzer
pip install -r requirements.txt
python app.py
```
